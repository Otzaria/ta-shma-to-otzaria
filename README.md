# ta-shma-to-otzaria

מייצא נתוני ביוגרפיות רבנים מ-API של תא שמע לקובץ נתונים ייעודי של אוצריא, ומפרסם GitHub Release חדש רק כאשר הנתונים השתנו.

> **שימוש פרטי בלבד:** הנתונים המיוצאים כאן שייכים ל[תא שמע](https://tashma.co.il) ומיועדים לשימוש פרטי במסגרת תוכנת אוצריא בלבד. אין להשתמש בקבצים או בנתונים לכל מטרה אחרת.

## איך זה עובד

Workflow בשם **Build biographies release** רץ אחת לשלושה ימים (וגם ידנית דרך Actions → Run workflow):

1. מושך את ערכי הרבנים מה-API של תא שמע (בהרשאת `rabanan:read`).
2. בונה קובץ נתונים ייעודי ומחשב חתימת תוכן.
3. משווה מול ה-hash של הרילייס האחרון; אם אין שינוי — לא נוצר רילייס.
4. אם יש שינוי — נוצר רילייס `bio-YYYYMMDD-HHMMSS` עם `biographies.tsb` ו-`biographies.sha256`.

תוכנת אוצריא מורידה את הרילייס האחרון בזמן ריצה, במסגרת מערכת עדכוני הנכסים הנלווים שלה.

## סודות (Secrets)

| שם | תוכן |
|---|---|
| `KEY` | מפתח ה-API של תא שמע |
| `OBF_KEY` | פרמטר פנימי של תהליך הבנייה |
